# Shivam Pandey · Portfolio (v3, neo-brutalist)

Static site: plain HTML, CSS and JavaScript, no build step.

## Files
- `index.html`: content and structure
- `styles.css`: design tokens (colours, borders, shadows) at the top, then each section
- `script.js`: dark mode, mobile menu, active nav link, case-study pop-ups, copy email, write-email menu

## Assets you add (next to index.html)
    assets/img/profile.jpg       hero photo
    assets/img/fund-flow.png     project screenshot, 770 x 485 px
    assets/img/docquery.png      project screenshot, 770 x 485 px
    assets/img/skillbridge.png   project screenshot, 770 x 485 px
    assets/resume.pdf            résumé

Until a screenshot exists, the card shows a generated title card. When the file is added, it replaces the title card automatically.
